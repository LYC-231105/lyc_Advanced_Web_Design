01看代码找错

20 分

① 图片放大后越界，文字定位也不对

.box li 缺少裁剪和定位参照。加上 overflow: hidden 后，图片放大的部分会被裁掉；加上 position: relative，绝对定位的文字条才会贴着自己的卡片底部。

.box li {
  width: 300px;
  position: relative; /* 让文字以这张卡片为参照 */
  overflow: hidden;  /* 放大后不能盖住旁边的卡片 */
}

② 移入有动画，移出却突然恢复

截图把图片的 transition 写在了 :hover 中，文字的默认样式也没有过渡。应把过渡放回普通选择器，悬浮时只改目标值，同时补上文字的展开规则。

.box img {
  width: 100%;
  transform: scale(1);
  transition: transform .6s ease;
}
.box li:hover img { transform: scale(1.2); }

.txt {
  position: absolute;
  left: 0;
  bottom: 0;
  width: 100%;
  height: 40px;
  overflow: hidden;
  background: rgba(0, 0, 0, .6);
  transition: height .6s ease;
}
.box li:hover .txt { height: 144px; }

③ 卡片挤在一行，宽度也被压缩

display: flex 本身没错，但 Flex 默认不换行，而且子项允许收缩。保留 Flex，补上换行、间距并禁止卡片收缩；列表自带的圆点和缩进也一起清掉。

.box {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
  list-style: none;
  padding: 0;
  margin: 0;
}
.box li { flex: 0 0 300px; }

这里保留题目中的 300px。上面的演示区较窄，实际用 calc((100% - 32px) / 3) 排三列。

03原理简答

25 分

1. “子绝父相”是什么位置关系？

父元素设置相对定位，仍然占着原来的位置。子元素设置绝对定位后脱离普通文档流，以最近的已定位祖先为参照。这里文字条的 left: 0; bottom: 0; 就是贴住 li 的左下角。

2. overflow: hidden 在这次练习中有哪两个作用？

一是裁掉图片缩放后超出卡片的部分，避免挡住邻居。二是裁掉文字条当前高度以外的内容，让描述先藏起来，等文字条变高后再逐渐露出。

3. scale(1.2) 会把实际占位撑大吗？

不会。transform 改变的是元素绘制出来的样子，不会重新计算它在普通布局中的占位，所以旁边的卡片不会被挤走。但画面可能越界，仍然需要父元素做裁剪。

4. transition 写在 hover 和普通选择器上有什么区别？

只写在 :hover 上，鼠标移入时有过渡，移出后这条规则就失效，通常会直接恢复。写在普通选择器上，移入和移出时都能读到过渡设置，两边都能平滑变化。

5. 一次代码排查记录

检查文件夹里的 picture_above_text.css 时，发现图片悬浮规则写成了 transition: scale(1.5)。这个值不是合法的过渡写法，浏览器会忽略，所以图片不会按预期放大。修复方法是将它改为 transform: scale(1.2)，并在图片默认样式里设置 transition: transform .6s ease。

04拓展：返回顶部

选做 · 15 分

用锚点跳到 id="top"，CSS 控制固定位置和悬浮效果。页面右下角就是实际效果，没有用 JavaScript。

<a class="back-top" href="#top" aria-label="返回顶部">↑</a>

html { scroll-behavior: smooth; }
.back-top {
  position: fixed;
  right: 24px;
  bottom: 24px;
  z-index: 100;
  opacity: .5;
  transition: opacity .2s ease, transform .2s ease;
}
.back-top:hover {
  opacity: 1;
  transform: scale(1.08);
}

容易写混的两个属性

transform 决定怎么变，比如放大到 1.2 倍。

transition 决定变化过程，比如用 0.6 秒完成。

检查时看这几处

  • 图片放大后有没有越界
  • 鼠标移出时有没有过渡
  • 文字是不是相对自己的卡片定位
  • 1、3、5 张卡片能不能铺满文字层
