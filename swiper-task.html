① 引入组件与三层骨架

Swiper 是原生 JavaScript 轮播组件库，需要同时引入 CSS 和 JS。本项目使用本地的 swiper/ 文件，离线也能运行。结构从外到内为 .swiper 容器、.swiper-wrapper 轨道、.swiper-slide 单张内容。

<link rel="stylesheet" href="swiper/swiper-bundle.min.css">
<script src="swiper/swiper-bundle.min.js"></script>
<div class="swiper">
  <div class="swiper-wrapper">
    <div class="swiper-slide">照片、标题和简介</div>
  </div>
</div>

② 拖动、圆点与箭头

初始化后可用鼠标或触摸滑动；pagination 指向圆点容器，clickable: true 允许点圆点跳转；navigation 中的 prevEl / nextEl 指定上一张、下一张按钮。原版最小轮播的动画时长为 500ms，分页导航示例为 600ms。任务三展台可直接体验拖动、圆点和箭头。

③ 自动播放与循环

loop 控制首尾循环，autoplay.delay 控制每张停留时间，speed 控制切换动画时长；disableOnInteraction: false 让手动翻页后自动播放继续。原版基础自动播放示例的 delay 为 2600ms、speed 为 700ms；效果实验台为 3200ms 与 800ms，本页的作业轮播按后者设置。

④ 效果与布局参数

原版演示 slide、fade、cube、coverflow、flip、cards 六种效果，任务二增加 creative。slidesPerView 控制可见张数，spaceBetween 控制间距；动态更换 effect 时需销毁旧实例再重建。

creative 参数调试：上一张卡片的旋转角度

打开项目内置的官方 creative 示例 →

上一张：缩小、左移，并绕 Y 轴转一个角度；下一张：先在右侧以 0.86 倍大小等待，进场时放大到 1。改下面的角度后点「应用」，轮播会切到 creative 并用新角度重建。答辩时可以直接点「一键改成 20 度」。

用自己的话解释：prev 描述左侧上一张离开中心后的状态；next 描述右侧下一张进入中心前的状态。translate 的 X/Y 百分比相对单张 slide 自身的宽/高，Z 数值为像素；rotate 的三个值依次控制 X/Y/Z 轴旋转角度，scale 控制缩放倍率。当前 next 的 scale 为 0.86，进场时恢复到 1，因此看起来逐渐放大。

任务三 / 播放速度设置

一张照片，想看多久？

这里控制上方照片自动切换的快慢。1000 毫秒 = 1 秒，数值越小，翻页越快。例如填 3200，每张先停留 3.2 秒，再用 0.8 秒切换到下一张，总共约 4 秒。

操作：输入时间 → 点击“应用时间” → 观察上方轮播。如果已暂停，请先点“继续导览”。
