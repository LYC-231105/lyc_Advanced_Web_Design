📌 页面说明

本页面为梁钰承的《高级网页设计》课堂实践导航首页，汇总了当前目录下除首页外的 7 个网页和 6 个 CSS 样式文件。课堂目录包含「HTML 基础」「自我介绍网页」「盒模型、层叠与继承/CSS选择器优先级」「上图下文/图上文字」「网页整体布局」「网页整体布局课后作业」和「CSS3 选择器与动画」。图片素材由各示例页面从 img 文件夹加载。本页面使用原生 HTML + CSS 编写，未依赖任何外部 CDN 资源。此外还有「LLM 应用实践」模块：四项能力演示页（端口 8817）与测试截图页。
